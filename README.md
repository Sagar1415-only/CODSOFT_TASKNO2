# CodSoft Data Analytics Internship - Task 2

## Exploratory Data Analysis (EDA)

### Objective
Perform Exploratory Data Analysis (EDA) on the Retail Sales Dataset to identify trends, distributions, relationships between variables, detect outliers, and derive business insights.

### Dataset
Retail Sales Dataset

### Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Tasks Performed
- Loaded and inspected the dataset
- Generated descriptive statistics
- Checked for missing values and duplicates
- Analyzed age and total amount distributions
- Detected outliers using box plots
- Visualized gender and product category distributions
- Created a correlation heatmap
- Analyzed relationships between Age and Total Amount
- Calculated summary statistics using groupby()

### Files
- `Task2 internship.ipynb`
- `retail_sales_dataset.csv`

### Outcome
The dataset was successfully analyzed using various statistical techniques and visualizations to identify trends, relationships, and business insights.
